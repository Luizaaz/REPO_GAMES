#  Jogo da Cobrinha

## Sobre o projeto

Este projeto é uma versão do clássico jogo da cobrinha (Snake), desenvolvido para navegador utilizando HTML, CSS e JavaScript.

O objetivo do jogo é controlar a cobrinha, coletar as maçãs e acumular pontos sem bater nas paredes, nos obstáculos ou no próprio corpo.

O jogo possui uma interface colorida e uma cobrinha com aparência de personagem, com olhos e sorriso.

## 🎮 Como jogar

* Utilize as **setas do teclado** ou as teclas **W, A, S e D** para movimentar a cobrinha.
* Colete as maçãs para ganhar pontos.
* Evite colidir com as paredes, os obstáculos e o próprio corpo.
* Tente alcançar a maior pontuação possível!

## 🛠️ Tecnologias utilizadas

* **HTML5:** estrutura da página.
* **CSS3:** estilização e aparência do jogo.
* **JavaScript:** movimentação, pontuação, colisões e regras.
* **Canvas:** desenho dos elementos do jogo.

##  Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta `snakegame`.
3. Abra o arquivo `index.html` em um navegador.
4. Comece a jogar!
